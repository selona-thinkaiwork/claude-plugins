# Selona Claude plugins

Claude Code plugins for Context Accelerator by Selona.

| Plugin | What it does |
|---|---|
| `context-accelerator-sync` | Two-way sync between your company's Context Accelerator usecases and a folder on your computer. |

## Install

You don't need a GitHub account. Install Git and Claude Code first, then run these two
commands in a terminal (PowerShell on Windows, Terminal on Mac):

```
claude plugin marketplace add selona-thinkaiwork/claude-plugins
claude plugin install context-accelerator-sync@context-accelerator
```

Restart Claude Code, then say **set up Context Accelerator sync**.

## Update

```
claude plugin marketplace update context-accelerator
claude plugin update context-accelerator-sync@context-accelerator
```
